# 管理员手册

管理员拥有 ChronoFrame 的全部权限：用户管理、照片管理、相簿管理、系统设置、队列、日志、备份和所有用户的数据。

## 管理员登录

访问 `/signin`，使用邮箱和密码登录。普通用户同样通过邮箱和密码登录。

GitHub OAuth 暂时保留原有管理员登录逻辑，不作为普通用户注册入口。当前项目不开放自助注册，普通用户必须由管理员创建。

## 用户管理

入口：`后台 → 用户管理`

管理员可以：

- 创建普通用户。
- 重置用户密码。
- 启用或停用用户。
- 将普通用户提升为管理员。
- 将管理员降为普通用户。
- 删除普通用户。

系统有这些保护规则：

- 不能降级、停用或删除自己。
- 不能降级、停用或删除系统中的最后一个可用管理员。
- 删除管理员前必须先降级为普通用户。
- 删除普通用户时，该用户的照片、相簿和未完成任务会转移给执行删除操作的管理员。

这些限制是为了避免站点进入无人可管理的状态，也避免删除管理员时同时发生角色变更和数据转移造成歧义。

## 普通用户权限

普通用户登录后台后只能看到：

- 仪表盘。
- 相片列表。
- 相簿列表。

普通用户只能操作自己的数据：

- 只能上传自己的照片和视频。
- 只能创建、编辑、删除自己的相簿。
- 只能把自己的照片加入自己的相簿。
- 不能查看或操作其他用户的后台数据。

如果普通用户尝试访问别人的资源，服务端返回 404，而不是 403。这样可以避免泄露资源是否存在。

## 照片管理

入口：`后台 → 相片`

后台照片列表支持：

- 查看照片标题、文件名、拍摄时间、上传/更新时间、所有者、所属相簿、隐藏状态等信息。
- 单张编辑照片信息。
- 单张设置照片所属相簿。
- 批量设置照片所属相簿。
- 删除照片。
- 根据权限显示全部照片或当前用户照片。

管理员看到全站照片；普通用户只看到自己的照片。

### 所属相簿展示

照片列表会直接展示照片所在的所有相簿，不折叠隐藏。这样可以快速判断一张照片是否已经归档，也方便批量调整归属。

### 无归属照片筛选

编辑相簿选择照片时，支持筛选“无任何归属相簿”的照片。这适合整理刚上传但还没有放入相簿的内容。

## 相簿管理

入口：`后台 → 相簿`

相簿支持：

- 创建、编辑、删除。
- 添加或移除照片。
- 设置隐藏状态。
- 展示相簿所有者。
- 展示相簿是否隐藏。

隐藏相簿不会出现在公开相簿列表中。隐藏相簿只对所有者和管理员可见。

## 公开访问密码

入口：`后台 → 设置 → 基础设置`

可以配置：

- 是否启用访问密码。
- 设置或更换访问密码。
- 匿名访客可预览的照片数量。
- 匿名访客可预览的相簿数量。

当前访问策略不是“一进入站点就要求输入密码”，而是：

1. 匿名访客可以先看到有限内容。
2. 超出预览数量、访问受保护媒体或查看更多时，需要输入访问密码。
3. 输入成功后，服务端签发 30 天有效的 HttpOnly Cookie。
4. 登录用户视为内部用户，不需要输入访问密码。

修改访问密码或关闭保护时，旧凭证会立即失效。

## 系统设置

管理员可以在后台设置中管理：

| 设置组   | 内容                                     |
| -------- | ---------------------------------------- |
| 基础设置 | 站点标题、标语、头像、访问密码、预览数量 |
| 存储设置 | 本地、S3、OpenList 存储提供器            |
| 隐私设置 | 上传时是否自动擦除 GPS 信息              |
| 地图设置 | Mapbox、MapLibre、高德地图               |
| 系统设置 | GitHub OAuth、重复文件策略、数据库备份   |
| 统计脚本 | 自定义头部/底部统计脚本                  |
| 站点备案 | ICP、公安备案、自定义页脚等              |

普通用户不能访问这些设置。

## 队列管理

入口：`后台 → 队列管理`

上传照片和视频后，解析 EXIF、生成缩略图、逆地理编码、Live Photo 匹配、视频转码等工作会进入队列。

管理员可以：

- 查看队列状态。
- 重试失败任务。
- 清理任务。
- 查看队列统计。

如果上传后长时间没有缩略图、无 GPS、视频无法播放，优先检查队列页面和系统日志。

## 系统日志

入口：`后台 → 系统日志`

系统日志用于定位：

- 上传失败。
- S3/COS 权限错误。
- EXIF 解析异常。
- 逆地理编码失败。
- 视频转码失败。
- 备份邮件发送失败。
- 媒体代理返回 404/500。

排障时建议同时查看 Docker 日志和后台系统日志。
