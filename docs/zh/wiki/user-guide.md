# 访客与普通用户手册

本文说明匿名访客和普通登录用户如何使用 ChronoFrame。

## 匿名访客

匿名访客可以访问公开页面：

- 首页 `/`
- 公开相簿 `/albums`
- 公开相簿详情 `/albums/:albumId`
- 照片详情 `/:slug`
- 地球仪 `/globe`
- 流光相片墙 `/album-flow`

如果站点启用了访问密码，匿名访客默认只能看到有限数量的内容。默认限制通常是：

- 前 10 张公开照片。
- 前 1 个公开相簿。

具体数量由管理员在后台配置。

## 输入访问密码

当你点击“查看更多”、打开超出预览范围的照片或访问受保护媒体时，系统会跳转到访问密码页面。

验证成功后：

- 会回到你原本想访问的页面。
- 浏览器会保存 30 天访问凭证。
- 下次访问同一站点时通常不需要再次输入。

访问凭证保存在服务端签名的 HttpOnly Cookie 中，前端 JavaScript 无法读取。

## 普通用户登录

普通用户账号由管理员创建，不支持公开注册。

登录后你可以：

- 查看仪表盘。
- 上传照片、视频和 Live Photo。
- 管理自己的照片。
- 创建和管理自己的相簿。
- 查看公开站点时无需输入访问密码。

你不能：

- 管理其他用户的照片或相簿。
- 进入用户管理、队列管理、系统日志、系统设置。
- 修改自己的角色。
- 自助重置密码。

如果忘记密码，请联系管理员重置。

## 上传照片和视频

后台入口：`相片 → 上传`

支持常见图片格式：

- JPEG / JPG
- PNG
- WebP
- GIF
- BMP
- TIFF
- HEIC / HEIF

也支持视频：

- MP4
- MOV

上传后系统会自动处理：

- 读取 EXIF 信息。
- 解析拍摄时间。
- 解析 GPS。
- 生成缩略图。
- 检测 Live Photo / Motion Photo。
- 对 HEVC/H.265 视频生成可播放的 H.264 版本。
- 通过位置服务进行逆地理编码。

大文件和视频处理可能需要一些时间。上传完成后如果短时间内看不到缩略图或位置，可以稍等并刷新，或联系管理员查看队列。

## 相簿使用

普通用户可以创建自己的相簿，并把自己的照片加入相簿。

相簿可以设为隐藏：

- 非隐藏相簿会进入公开相簿列表。
- 隐藏相簿只对所有者和管理员可见。

公开画廊会聚合所有用户的非隐藏内容。也就是说，普通用户上传的非隐藏照片和相簿默认可以进入公开站点。

## 照片详情页

照片详情页支持：

- 查看大图。
- 查看 EXIF。
- 查看所属相簿。
- 查看所有者信息。
- 视频播放。
- Live Photo 播放。
- 图片缩放、拖拽、旋转和全屏查看。
- 自动播放下一张可见照片。

如果你是匿名访客且没有输入访问密码，只能浏览管理员允许预览范围内的照片。

## 地球仪和流光墙

地球仪和流光墙也遵守访问密码和预览数量限制。

如果未输入访问密码：

- 地球仪只展示预览范围内且有 GPS 的公开照片。
- 流光墙只展示预览范围内的公开照片。
- 进入超出范围的照片详情时会要求输入访问密码。
