# ChronoFrame Wiki 总览

这个 Wiki 面向当前 fork 的 ChronoFrame，而不是仅覆盖上游原版功能。它把项目的部署、权限模型、公开访问密码、媒体处理、存储、地图、备份和常见故障集中到一套可以直接查阅的文档里。

如果你只是想把站点跑起来，先看[部署与升级](./deployment.md)。如果你已经部署完成，想知道后台怎么使用，看[管理员手册](./admin-guide.md)。如果你遇到上传、图片 500、地球仪卡顿、访问密码、S3/COS 之类的问题，看[运维与排障](./operations.md)。

## 项目定位

ChronoFrame 是一个自部署个人/家庭相册站点，核心目标是：

- 在线上传、管理、浏览照片、视频、Live Photo 和相簿。
- 支持公开画廊，但由站点访问密码和预览数量限制控制开放范围。
- 支持管理员和普通用户，多用户之间的数据隔离，管理员统一管理全站内容。
- 支持本地存储、S3 兼容存储和 OpenList 存储。
- 支持照片 EXIF、GPS、逆地理编码、地图和地球仪视图。
- 支持 SQLite 数据库、Docker 部署、定时数据库备份邮件发送。

## 当前 fork 的主要增强

相较于上游仓库，当前 fork 增加或强化了这些能力：

| 领域         | 能力                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------- |
| 多用户       | 后台创建用户、重置密码、启停账号、提升/降级管理员、删除普通用户并转移数据                |
| 权限隔离     | 普通用户只能管理自己的照片和相簿，管理员管理全部数据，越权资源返回 404                   |
| 公开访问控制 | 匿名用户无需一进入就输入密码，但只能预览前 N 张照片和前 M 个相簿；查看更多时输入访问密码 |
| 媒体保护     | 图片、缩略图、视频、Live Photo 和下载都走服务端鉴权代理，不再依赖公开对象直链            |
| 视频支持     | 支持 MP4/MOV 上传，支持 HEVC/H.265 转码为 H.264 播放格式                                 |
| 地图与定位   | 支持 Mapbox、MapLibre、高德地图，以及高德/Mapbox/Nominatim 逆地理编码                    |
| 视觉页面     | 新增 `/album-flow` 流光相片墙，受公开预览限制控制                                        |
| 相片管理     | 后台展示相片所属相簿，支持单张和批量设置相簿，编辑相簿时可筛选无归属照片                 |
| 备份         | 后台配置定时数据库备份，将 SQLite 备份发送到邮箱，并支持保留策略                         |
| 容器部署     | 提供公开 GHCR 镜像和容器内可靠的数据、临时目录默认路径                                   |

更多差异请看[与上游仓库的差异](../guide/fork-differences.md)。

## 角色与访问边界

ChronoFrame 有三类访问者：

| 访问者   | 可以做什么                                                   | 不能做什么                                           |
| -------- | ------------------------------------------------------------ | ---------------------------------------------------- |
| 匿名访客 | 查看公开首页、公开相簿、公开照片、地球仪和流光墙中的预览内容 | 超过预览数量、访问受限媒体、进入后台、上传或管理内容 |
| 普通用户 | 登录后台，查看仪表盘，上传和管理自己的照片、相簿             | 管理别人数据、访问系统设置、队列、日志、用户管理     |
| 管理员   | 管理全部照片、相簿、用户、系统设置、队列、日志和备份         | 降级/停用/删除自己，删除最后一个可用管理员           |

公开画廊默认聚合所有用户的非隐藏内容。隐藏相簿只对所有者和管理员可见。

## 关键页面

### 公开页面

| 页面               | 说明                       |
| ------------------ | -------------------------- |
| `/`                | 站点首页，展示公开可见照片 |
| `/albums`          | 公开相簿列表               |
| `/albums/:albumId` | 公开相簿详情               |
| `/:slug`           | 相片或视频详情页           |
| `/globe`           | 地球仪照片分布             |
| `/album-flow`      | 流光相片墙                 |
| `/access`          | 访问密码验证页             |
| `/signin`          | 登录页                     |

### 后台页面

| 页面                    | 说明               |
| ----------------------- | ------------------ |
| `/dashboard`            | 仪表盘             |
| `/dashboard/photos`     | 相片管理           |
| `/dashboard/albums`     | 相簿管理           |
| `/dashboard/users`      | 用户管理，仅管理员 |
| `/dashboard/queue`      | 队列管理，仅管理员 |
| `/dashboard/logs`       | 系统日志，仅管理员 |
| `/dashboard/settings/*` | 系统设置，仅管理员 |

普通用户直接访问管理员页面时会被重定向到仪表盘。

## 核心数据流

```mermaid
flowchart LR
  A["用户上传文件"] --> B["创建上传任务"]
  B --> C["写入对象存储"]
  C --> D["后台队列解析媒体"]
  D --> E["提取 EXIF/GPS/视频信息"]
  E --> F["生成缩略图和展示资源"]
  F --> G["写入照片记录和 ownerUserId"]
  G --> H["公开页/后台按权限查询"]
  H --> I["媒体代理统一鉴权并返回文件"]
```

上传者身份会贯穿队列和生成的照片记录。普通用户上传的照片归属于自己，管理员上传的照片归属于管理员本人。
